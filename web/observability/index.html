Topología y rutas

Volumen lógico de WebSocket por worker. La API de coordinación y el flujo de eventos son rutas distintas; una línea no certifica disponibilidad.

Verde: juego · azul: coordinación · dorado: eventos. Las flechas animadas indican muestras recientes con actividad; la ruta dibujada por sí sola no confirma disponibilidad. Valores de payload, no facturación.

Kafka y recolección

Un broker KRaft. Sin alta disponibilidad. El juego continúa si se pierde telemetría.

Comparar servidores

RTT: ping/pong del gateway al navegador, no tiempo de simulación. Los bytes lógicos, los bytes de transporte comprimido y los contadores de interfaz EC2 tienen ámbitos distintos; no representan facturación.
