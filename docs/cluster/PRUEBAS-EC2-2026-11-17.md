## Repetir y abrir el despliegue sin cambiar DNS

Desde la raíz del repositorio:

```sh
python3 scripts/cluster/verify-private-network.py
node scripts/cluster/preview.mjs
```

La primera orden prueba IP privadas mediante SSM. La segunda abre Chromium con una resolución local exclusiva de esa ventana hacia `3.23.131.44`: conserva Host/SNI para validar el certificado existente, no edita DNS ni el archivo hosts, y no usa la entrada antigua. Cerrar la ventana elimina el perfil temporal.

Para repetir la prueba automatizada del navegador:

```sh
SMOKE_URL=https://redhorizon.lat SMOKE_RESOLVE_IP=3.23.131.44 node scripts/smoke-online-production.mjs
```

No ejecutar inyección de fallos/carga contra un clúster con jugadores reales. Los scripts conservan sus protecciones de aislamiento.
